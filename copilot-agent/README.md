# fAlpha for Microsoft 365 Copilot

A declarative agent that connects Microsoft 365 Copilot to fAlpha's hosted MCP server
(`https://agent.falpha.ai/mcp`). The agent package only points at the server; nothing is
rehosted. Users sign in with their fAlpha account (OAuth 2.1 with dynamic client registration).

## What is in this folder

`appPackage/` holds the content for the agent package:

- `declarativeAgent.content.json`: name, description, instructions, conversation starters and
  disclaimer.
- `ai-plugin.json`: the plugin manifest (schema v2.4). It uses dynamic tool discovery, so the
  agent always sees the server's current tools, including the ones that return card views.
- `manifest.content.json`: names, descriptions and developer links for the app manifest.
- `color.png` (192 x 192) and `outline.png` (32 x 32).

The authentication reference in `ai-plugin.json` is created by Microsoft 365 Agents Toolkit when
the agent is built, so the project itself is generated by the toolkit and this content is applied
to it.

## Build

1. Install Visual Studio Code and Microsoft 365 Agents Toolkit 6.12.0 or later.
2. In the toolkit: Create a New Agent/App, Declarative Agent, Add an Action, Start with an MCP
   Server. Enter `https://agent.falpha.ai/mcp` and choose **OAuth (with dynamic registration)**.
3. Copy the content from `appPackage/` into the generated project's `appPackage/` folder, keeping
   the generated identifiers and the authentication reference.
4. In the toolkit's Lifecycle pane, select Provision. Test at `https://m365.cloud.microsoft/chat`.

## Requirements

- A Microsoft 365 tenant where custom app upload is enabled.
- A fAlpha account to sign in with.
